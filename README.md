# AI workflow

개발 작업에서 AI에게 요청할 때 참고하는 한국어 프롬프트와 작업 메모 양식입니다. 프로젝트 파악, 구현, 리뷰, 인수인계에 필요한 내용을 모았습니다.

## 구성

| 파일 | 용도 |
|---|---|
| [AGENTS.md](AGENTS.md) | 프로젝트에서 적용할 작업 원칙 |
| [PROMPTS.md](PROMPTS.md) | 상황에 따라 골라 쓰는 요청문 |
| [CHECKLIST.md](CHECKLIST.md) | 요구사항과 변경 사항을 점검하는 질문 |
| [TEMPLATES.md](TEMPLATES.md) | 작업 메모, 리뷰, 인수인계 양식 |
| [TOOLING.md](TOOLING.md) | 공개 도구 비교, 필요한 스킬만 가져오는 방법 |

## 사용

작업할 프로젝트의 기존 문서와 규칙을 먼저 확인한 뒤 필요한 지침을 적용합니다.

```text
이 프로젝트의 README와 관련 코드, 설정을 읽어줘.
이 지침 모음에서 AGENTS.md를 참고하고,
프로젝트에 이미 정해진 규칙과 구조에 맞춰 작업해줘.
```

하위 폴더에 지침을 두었다면 실제 파일 경로를 함께 전달합니다. 프롬프트에 나오는 파일 이름과 출력 형식은 프로젝트의 기존 방식에 맞춰 조정합니다.

이 저장소는 읽어서 적용하는 지침 모음입니다. 플러그인 설치나 모델 설정 변경은 하지 않습니다. 요구를 더 확인할 때, 계산 방법을 선택할 때, 검증하거나 구현을 이해할 때는 PROMPTS.md에서 해당 요청문만 골라 사용합니다.

## 작업 흐름

1. 변경할 동작과 확인할 결과를 정합니다.
2. 관련 입력, 코드와 제약을 확인합니다.
3. 작동하는 작은 단위로 구현하고 검증합니다.
4. 리뷰에서 발견한 문제를 확인하고 수정합니다.
5. 실행 방법과 중요한 결정, 다음 작업을 기록합니다.

여러 세션을 사용할 때는 파일별 수정 담당을 정하고 저장된 작업 상태를 공유합니다. 실행 방법은 대상 프로젝트의 README에 정리하고, 작업을 이어갈 정보는 필요할 때 HANDOFF.md에 남깁니다.

## 자료 활용

적용할 프로젝트의 자료 사용·접근 권한·데이터 처리 정책을 따릅니다. 외부 자료를 참고한 경우 출처와 적용한 범위를 작업 기록에 남깁니다. 양식은 프로젝트의 실제 요구와 코드에 맞춰 작성합니다.
